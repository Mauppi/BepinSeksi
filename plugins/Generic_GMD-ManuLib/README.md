# The scripts and things

<br>NONE OF THE SCRIPTS ARE SYNCED! <br><br>USE JCLIENTSYNC!

MLCheckOnShip: Attaches to a scrap item, allows you to call it on start or whenever you want and does something whether it is in the ship or not.<br>
MLItemValueModifier: Attaches to a scrap item, allows you to modify it's value by adding, multiplying, and other stuff. Allows percentages too. <br>
MLKeyItem: Key with multiple uses and the ability to fire off unity events on use.<br>
MLLadderItem(WIP): Extension ladder script with customizable timer. Can also have infinite use.<br>
MLObjectEviscerator: Kills the referenced object. Yeah.<br>
MLPrintStewie: Prints Stewie Griffin in the console.<br>
MLRunOnHost: Runs a unity event on host only. Also has the ability to do it on only clients.<br>
MLRunOnWakeup: Allows Unityevents to be fired off on Start, Awake, OnEnable, or OnDisable.<br>
