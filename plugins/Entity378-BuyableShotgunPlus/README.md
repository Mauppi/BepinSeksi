# BuyableShotgunPlus
The shotgun and its ammo can now be purchased from the terminal.\
This mod should ensure that both the shotgun and ammo are saved correctly when a save is loaded again.\
The price of the shotgun and the ammo are configurable\
The configs are fully synced.
